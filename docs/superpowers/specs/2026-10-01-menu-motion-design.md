# Motion เมนู — Design Spec

**Date:** 2026-10-01
**Status:** Approved (พีพีสั่งเขียนแผนลงมือ 2026-10-01)
**Scope:** `RightMenuDrawer` ทั้งมือถือเต็มจอและแผงเดสก์ท็อป ไม่รวม bottom nav, sidebar ล็อบบี้, หรือ hub อื่น

## Goal

ให้เมนูมีสามจังหวะที่เห็นด้วยตา ไม่ใช่แค่พื้นเปลี่ยนสี: เปิดแบบ stagger, เมาส์บนเดสก์ท็อปเป็นการ์ดลอย, นิ้วบนมือถือเป็นการกดยุบ แอนิเมชันเปิดเมนูต้องไม่ทับท่าชี้และท่ากด

## Confirmed decisions

| Topic | Decision |
|-------|----------|
| จังหวะ | เปิดแบบ stagger + hover ลอยบนเดสก์ท็อป + กดยุบบนมือถือ |
| วิธีทำ | CSS แยกช่องทาง ไม่ใส่ state จาก React |
| ตอนเปิด | `opacity` และ `translate` เท่านั้น |
| ตอนชี้และกด | `transform` เท่านั้น |
| การ์ดลอย | เฉพาะ `@media (hover: hover) and (pointer: fine)` |
| แถวแนวตั้งบนเดสก์ท็อป | ไม่ยกทั้งแถว ขยับไอคอนกับลูกศร |
| มือถือ | ใช้ `:active` สำหรับยุบ ไม่ให้ `:hover` ค้างหลังปล่อยนิ้ว |
| ลดการเคลื่อนไหว | ไม่มี stagger ไม่มีการลอยหรือยุบ เหลือเปลี่ยนสีพื้น |
| ไฟล์ | แก้ `app/styles/menu-drawer.css` อย่างเดียว |

## Surfaces

| พื้นผิว | ที่อยู่ | ท่า |
|---------|--------|-----|
| โลโก้ | มือถือ | เลื่อนลงแล้วค่อยชัดตอนเปิด |
| Avatar | มือถือ | ขยายขึ้นหลังโลโก้ |
| การ์ดกริด | มือถือ 3 คอลัมน์ และเดสก์ท็อป 4 คอลัมน์ | stagger ตอนเปิด, ลอยเมื่อเมาส์ชี้บนจอ fine pointer, ยุบเมื่อกด |
| แถวเมนู | แผงเดสก์ท็อป กลุ่มแนวตั้ง | stagger ตอนเปิด, ไอคอนกับลูกศรขยับเมื่อชี้, ยุบเล็กน้อยเมื่อกด |

ลำดับ stagger ของรายการเริ่มซ้ายบนไปขวา แล้วลงแถวถัดไป ค่าหน่วงคือ `120ms + index * 42ms` ระยะแอนิเมชันรายการ `460ms` โลโก้ `420ms` avatar `520ms` เริ่มหลังโลโก้ `70ms`

## Motion spec

ใช้ token ที่มีอยู่: `--motion-fast` (160ms), `--ease-out`, `--ease-in`, `--accent-primary` ไม่เพิ่ม token ใหม่

### เปิดเมนู

เล่นใหม่ทุกครั้งที่ dialog เปิด เพราะโหนดถูก mount ใหม่พร้อมคลาส entrance

- โลโก้: `opacity` 0 ไป 0.98, `translate` จาก `0 -10px` ไป `0 0`
- Avatar: `opacity` 0 ไป 1, `scale` 0.82 ไป 1 ใช้คุณสมบัติ `scale` ไม่ใช้ `transform`
- การ์ดและแถว: `opacity` 0 ไป 1, `translate` จาก `0 14px` ไป `0 0`, `scale` 0.94 ไป 1

Keyframe ของ entrance ห้ามกำหนด `transform`

### เดสก์ท็อป — เมาส์ชี้การ์ดกริด

ภายใต้ `(hover: hover) and (pointer: fine)` เมื่อ `:hover` หรือ `:focus-visible`

- การ์ด: `translateY(-8px) scale(1.03)` พื้นไล่เทาอมม่วง เงาลงและ glow จาก `--accent-primary`
- ไอคอน: `translateY(-4px) scale(1.12)` พร้อม drop-shadow ม่วง
- ข้อความ: `translateY(-1px)` สีขาว
- ระยะ: `--motion-fast` ด้วย `--ease-out`

ขณะกด `:active` ชนะ `:hover` การ์ดเป็น `translateY(0) scale(0.97)` ไอคอน `scale(1.04)` ปล่อยแล้วกลับท่า hover ถ้าตัวชี้ยังอยู่

### เดสก์ท็อป — เมาส์ชี้แถวแนวตั้ง

ท่าชี้ของแถวอยู่ภายใต้ `@media (hover: hover) and (pointer: fine)` เช่นเดียวกับการ์ดลอย ขณะกด `:active` ชนะ `:hover`

- พื้นแถวสว่างขึ้น `rgb(255 255 255 / 0.05)`
- ไอคอน: `translateX(2px) scale(1.07)`
- ลูกศร: `translateX(3px)` พื้นวงสว่างขึ้น
- แถวไม่ใช้ `translateY` ทั้งก้อน
- กดค้าง: `scale(0.995)` และพื้นเข้มขึ้นอีกนิด

### มือถือ — กดการ์ด

- ไม่มีท่าลอย
- `:active`: การ์ด `scale(0.96)`, ไอคอน `scale(0.94)`, ระยะสั้นด้วย `--ease-in`
- ปล่อยนิ้วแล้วกลับสภาพพักก่อนนำทาง
- ห้ามมีกฎที่ทำให้ `:hover` บนจอ coarse ค้างเป็นท่าลอย

### โฟกัสคีย์บอร์ด

`:focus-visible` บนการ์ดได้ท่าเดียวกับ hover บวกวงโฟกัส `2px` สีพื้นหลังหน้า แล้ว `4px` จาก `--accent-primary` แถวแนวตั้งได้พื้นสว่างพร้อมเส้นในสีม่วง ไม่ใช้ outline เริ่มต้นของเบราว์เซอร์

### ลดการเคลื่อนไหว

เมื่อ `prefers-reduced-motion: reduce`

- ปิด animation ของโลโก้ avatar และการ์ด
- ปิด transition ของ `transform`
- `:hover` และ `:active` ไม่เปลี่ยน `transform`
- ยังเปลี่ยนสีพื้นของการ์ดและแถวได้

## CSS channels

| ช่อง | คุณสมบัติ | คลาส |
|------|-----------|------|
| เปิด | `opacity`, `translate`, `scale` | `.menu-enter-logo`, `.menu-enter-avatar`, `.menu-enter-item` |
| ชี้และกด | `transform` | `.menu-grid-tile`, `.menu-list-row` และลูก `.menu-grid-icon`, `.menu-grid-label`, `.menu-list-icon`, `.menu-list-chevron` |

คลาส entrance อยู่บนองค์ประกอบเดียวกับที่รับ hover ได้ ดังนั้น keyframe เปิดเมนูต้องไม่จอง `transform` หลังแอนิเมชันจบใช้ `animation-fill-mode: backwards` เพื่อไม่ตรึงค่าตอนจบไว้ทับ hover

ลบกติกา `@media (pointer: coarse)` ที่รีเซ็ต `:hover` ทิ้ง กติกานั้นทำให้บนบางเครื่องเห็นแค่สีพื้น

`RightMenuDrawer.tsx` คงคลาส `menu-enter-*` และตัวแปร `--menu-enter-i` ไว้ ไม่เพิ่ม event pointer และไม่เพิ่มไฟล์ CSS

## Out of scope

- ไม่เปลี่ยนโครง dialog, โลโก้, avatar, หรือรายการเมนู
- ไม่ใส่ motion ให้ bottom nav, sidebar, หรือการ์ดล็อบบี้
- ไม่เพิ่มไลบรารีแอนิเมชัน
- ไม่ commit ในรอบเขียน spec นี้ จนกว่าพีพีจะสั่ง

## Acceptance

ถือว่าผ่านเมื่อตรวจด้วยตาได้ครบนี้

1. เดสก์ท็อป: เปิดเมนูแล้วรายการโผล่ทีละช่อง วางเมาส์บนการ์ดกริดแล้วการ์ดลอยขึ้นพร้อม glow และไอคอนขยาย วางบนแถวแนวตั้งแล้วไอคอนกับลูกศรขยับโดยแถวไม่ลอย กดค้างแล้วการ์ดยุบ
2. มือถือ: เปิดแล้วยัง stagger แตะค้างแล้วการ์ดยุบ ปล่อยแล้วไม่ค้างท่าลอย
3. เปิดลดการเคลื่อนไหวในระบบ: ไม่มี stagger ไม่มีการลอยหรือยุบ เหลือสีพื้น
4. โฟกัสด้วยคีย์บอร์ด: เห็นท่าเดียวกับ hover พร้อมวงโฟกัส
